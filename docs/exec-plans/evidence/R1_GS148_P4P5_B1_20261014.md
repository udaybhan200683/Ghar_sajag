## Audit finding

`CloudSync` already reads the journal, orders urgent work, reconstructs the
original payload plus authenticated enrollment generation, caps batches/retry
hints and persists completion only after exact authenticated COMMITTED.
`HttpBackendTransport` validates exact response grammar; the S3 HTTPS adapter
requires an externally supplied origin, CA and opaque Authorization value.
`DurableEventCommit` atomically writes the event, incident and notification
outbox before COMMITTED, with current Home/Hub/epoch/generation policy in the
ownership registry. Existing P2-D tests prove these independent contracts.

No target runtime task calls `CloudSync::drive_batch`. The target has no GS-109
production credential issuer/verifier, trusted Home/Hub/epoch source or approved
owner-versus-network worker concurrency contract. Calling synchronous HTTPS
from the real-time ESP-NOW owner or using fixture credentials commercially is
not authorized. The bounded worker will remain unconfigured on target until
those authorities are defined, while its host-injected production path can be
tested without weakening fail-closed behavior.
