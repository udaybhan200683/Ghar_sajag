# GS-114 C8-P8 physical lost-application-ACK qualification — 2026-10-14

## Disposition

**C8-P8 physical PASS, with stimulus-time precision limitation.** The recorded
physical transaction proves a real PIR event was durably committed, its first
application ACK was withheld after commit, the Node retried the same EventKey,
the Hub applied one logical effect, and an authenticated Durable ACK eventually
retired the Node event. The operator later clarified that real movement happened
before the direct action prompt; its exact physical timestamp is not available.
The event arrived within the armed fixture window, but the prompt itself is not
claimed as the cause of this EventKey and no stimulus-to-event latency is
claimed.
