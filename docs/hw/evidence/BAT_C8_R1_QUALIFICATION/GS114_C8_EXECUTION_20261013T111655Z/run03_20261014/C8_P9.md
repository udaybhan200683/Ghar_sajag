# C8-P9 — ACK and signed FOTA sleep inhibition

## 2026-10-14 — software validation supplement

The P9 software behavior has now been audited and validated separately from
physical acceptance. See the [dated software validation evidence](../run05_software_20261014/C8_P9_SOFTWARE_VALIDATION_20261014.md).

- **ACK software: PASS.** A permanent production-code NodeRuntime/HubRuntime
  host scenario verifies an unresolved authenticated Durable ACK keeps the
  exact event pending and prevents sleep beyond the 10,000 ms receive budget;
  a valid exact-key Durable ACK retires it and normal idle sleep eligibility
  returns. `make gs150-host-test` and ASan/UBSan each passed with 1,500 checks.
- **ACK physical: BLOCKED / NOT_RUN.** A real bounded ACK-hold interval and
  target observation of no premature sleep are still required. The P8
  one-shot loss fixture is insufficient to demonstrate the longer window.
- **FOTA software: PASS, host/state-machine evidence only.** Existing adapter,
  host, board-stack and fixture-orchestration checks cover authentication and
  hash rejection, maintenance sleep inhibition, interrupted/expired transfer,
  pending-event preservation and boot-health rollback decisions. They do not
  prove target signature acceptance.
- **Signed FOTA physical: BLOCKED / NOT_RUN.** No matched signed test/recovery
  pair, trusted signing provenance, supported authenticated trigger or safe
  target recovery plan is available.
- No hardware or firmware was touched, and no physical action was requested.
  P10 remains separate under GS-149. GS-114 remains In Progress.

The original fixture and physical dispositions below remain historical evidence
from their capture date; this supplement records the later software-only work
without rewriting those observations.

- **Disposition:** BLOCKED / NOT_RUN. P8 and the dedicated P9 fixtures have not run.
- **ACK subcase:** current Hub image has no ACK suppression control, and the confirmed setup has no directional RF attenuator/shield. The proposed P8 one-shot ACK drop would permit only the normal retry interval before a later ACK; by itself it does not hold the ACK open for a longer measured observation window. A controlled bounded hold mode or the qualified directional fixture is still required for P9's independent sleep-inhibition window. The C3 native USB console is not a reliable live observer during light sleep, so the authenticated post-wake/Hub observation method must prove no sleep entry during the actual pending window.
- **FOTA subcase:** no matched signed C3 test image plus known recovery image and signing/verification manifest was found in the current GS-114 evidence or fixture artifact directories. The installed S3 profile has `GS_HIL_BUILD=OFF` and `GS_HIL_CONTROL=OFF`; it exposes only isolated test commissioning/status and has no supported physical signed-FOTA trigger. Historical HW-M1 FOTA source is not a qualified signed-image pair or recovery plan.
- **Boundary:** do not fabricate signing authority, weaken signature validation, enable broad S3 HIL controls, or install an OTA image. If a signed pair, supported trigger and proven recovery procedure become available, obtain the required explicit confirmation for the exact FOTA install before starting. P10 remains a separate GS-149 current-measurement activity.
