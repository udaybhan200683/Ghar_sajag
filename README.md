# Ghar Sajag

Ghar Sajag is a privacy-conscious family check-in and home-risk awareness product for older adults living independently.

This repository contains:

- P0 requirements and software design
- Hardware planning and component lists
- UML, architecture and sequence diagrams
- Implementation progress
- Hardware-independent reference code
- Verification evidence and release snapshots

## Repository structure

- `docs/requirements` — product, P0 and software requirements
- `docs/hardware` — BOM, assembly and placement material
- `docs/architecture` — UML, architecture and sequence diagrams
- `docs/progress` — current implementation status
- `firmware` — reference implementation source
- `releases` — versioned source snapshots
