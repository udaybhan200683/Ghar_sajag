# Parivar Sathi v3.3.4 — dashboard routine layout

- Main banner is now an overall household status only.
- Routine-specific content is removed from the banner.
- Morning Routine is a first-class card directly below the banner, before I am OK.
- Card order: Morning Routine, I am OK, Main Door, Night Activity, Device Health.
- A real care concern can still turn the overall banner light red, but the specific problem is shown in the affected routine card.
- Device-health-only issues remain excluded from the care banner.
- Browser automation now verifies the new ordering and that routine text is not embedded in the overall banner.
